# UI/UX Brief

## Brand direction

Adwiz Media should feel sharp, active, and commercially useful. The design uses a strong editorial hero, high-contrast sections, direct copy, and clear calls to action so business owners understand the offer quickly.

## Primary users

- Local businesses that need social media management
- Startups that need a credible online presence
- Growing brands that want reach campaigns and lead flow
- Founders who want one partner for strategy, content, and execution

## Core flows

1. Visitor understands Adwiz in the first screen.
2. Visitor scans services and packages.
3. Visitor checks process and credibility signals.
4. Visitor submits the enquiry form.
5. Backend validates and stores the lead when a database is configured.

## Conversion points

- Header call-to-action
- Hero start button
- Package enquiry links
- Contact form
- Email, phone, and WhatsApp links

## Visual system

- Cards use restrained 8px radius for a more professional agency feel.
- Colors use black, white, red, blue, green, and yellow accents so the page does not feel one-note.
- Real workspace imagery is used for the hero and work section to make the agency subject clear.
- Buttons include icons for faster scanning and clearer actions.

## Future screens

- Admin lead dashboard
- Campaign planner
- Content calendar
- Client onboarding questionnaire
- Case study pages
